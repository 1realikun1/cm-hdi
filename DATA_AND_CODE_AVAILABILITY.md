# Data and code availability

The code and processed evaluation artifacts supporting the CM-HDI manuscript are available in this repository. The release includes spatially held-out regional predictions, fold definitions, model-selection records, constrained-synthesis weights, statistical-inference scripts, neural-baseline verification, and frozen processed input snapshots for the three study settings.

The released files support metric recalculation, statistical reanalysis, and rerunning the model-selection and constrained-synthesis stages from region-level processed inputs. Original EO rasters, third-party administrative boundary products, and the complete upstream raster-processing environment are not redistributed. Those source datasets remain available from their cited providers subject to the providers’ terms. Reconstructing the population-weighted EO features from source imagery therefore requires obtaining the cited source data separately.

Suggested manuscript wording:

> Code and processed evaluation artifacts are available at https://github.com/1realikun1/cm-hdi. Original EO rasters and third-party boundary products are not redistributed; the source datasets are identified in the manuscript and Supplement and remain subject to their providers’ terms.
